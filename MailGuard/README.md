# MailGuard – Email Spam and Phishing Detection System

## Run
```bash
python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000. On first run the model trains automatically (a few seconds) and is saved as `ml/model.joblib`. `database.db` is created automatically. NLTK stop words are downloaded on first run if internet is available; otherwise scikit-learn's stop-word list is used.

## How the ML works
`ml/preprocess.py` cleans text (lowercase, URL/money tokens, NLTK stop words and Porter stemming), `ml/train.py` builds a TF-IDF + Logistic Regression pipeline, trains on 80% of the data and reports accuracy on the unseen 20% (`ml/metrics.json`, shown on the Dashboard). `ml/predict.py` returns the label, per-class probabilities, and the terms that pushed hardest toward spam or phishing.

## Important: training data
`ml/data/seed_emails.csv` is a small **synthetic demo dataset** (generated by `ml/make_seed_data.py`) so the app runs out of the box. Its accuracy is not a real-world measure. For real use, download a labeled dataset (e.g. SpamAssassin, Enron-Spam, or a Kaggle phishing-email dataset), save it as `ml/data/emails.csv` with columns `subject,message,label` (`safe`/`spam`/`phishing`), and run:
```bash
python -m ml.train
```
Restart `python app.py` afterwards.

## API
`GET /api/health`, `POST /api/analyze`, `GET|DELETE /api/history`, `GET|DELETE /api/history/<id>`, `GET /api/analytics`.

## Structure
`app.py`, `backend/` (routes, database, analysis), `ml/` (preprocess, train, predict, data), `frontend/` (pages, css, js), `database.db`, `requirements.txt`.
