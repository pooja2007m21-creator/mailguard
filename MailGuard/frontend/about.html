About MailGuard

MailGuard classifies emails as Safe, Spam, or Phishing with a machine-learning model and explains the result with suspicious keywords, link checks, and text statistics.

How It Works

Subject + Message
↓
Cleaning, stop-word removal, stemming (NLTK)
↓
TF-IDF features (scikit-learn)
↓
Logistic Regression classifier
↓
Label + Confidence + Key Terms
↓
Link checks + Text Statistics

Limitations

  • The model is only as good as its training data. The bundled dataset is a small synthetic demo.
  • Link checks are rule-based warning signs, not a blocklist lookup.
  • Confidence is the model's probability, not a guarantee. Phishing emails can look legitimate.

Technology Stack

  • HTML5, CSS3, JavaScript
  • Python, Flask, SQLite
  • NLTK, scikit-learn, TF-IDF
